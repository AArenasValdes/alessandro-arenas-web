# Local web fonts

The WOFF2 files in this directory are Latin and Latin Extended subsets obtained from Google's official Fonts CDN on 2026-11-10. Their upstream family records and license texts are maintained in the Google Fonts repository.

- Instrument Serif: `https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1`
- Manrope: `https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700`
- Instrument Serif license: `https://github.com/google/fonts/blob/main/ofl/instrumentserif/OFL.txt`
- Manrope license: `https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt`

The downloaded license texts are `InstrumentSerif-OFL.txt` and `Manrope-OFL.txt`. The Manrope WOFF2 is variable and is declared locally for weights 400–700.
