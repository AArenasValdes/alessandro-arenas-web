INFORMACIÓN DE PRIVACIDAD

Privacidad y contacto

Este sitio es administrado por Alessandro Arenas, profesional independiente que ofrece servicios tecnológicos en Chile.

Qué información se utiliza

El formulario prepara en tu propio navegador un mensaje con los datos que decides escribir. Este sitio, en su versión entregada, no mantiene una base de datos, no envía el formulario a un servidor y no instala herramientas de analítica ni píxeles publicitarios.

Qué ocurre cuando abres WhatsApp

Al presionar el botón, si el servicio está configurado, se abre WhatsApp con un mensaje preparado. Al abrir WhatsApp, el mensaje preparado se entrega a esa plataforma para mostrarlo. Tú decides si lo envías a Alessandro. Si lo envías, se utiliza para responder tu consulta, evaluar el servicio solicitado y, si procede, preparar una propuesta comercial. La conversación está sujeta además a las políticas de WhatsApp.

Tu decisión y tus derechos

El envío es voluntario. Puedes solicitar información, actualización o eliminación de los datos que hayas compartido mediante el mismo canal de contacto. No se utiliza esta información para enviar publicidad no solicitada.

Servicios de terceros

La página enlaza a sitios externos, entre ellos Ventora, ICT Zella y, si se configuran, plataformas sociales. Esos sitios tienen sus propias condiciones.
