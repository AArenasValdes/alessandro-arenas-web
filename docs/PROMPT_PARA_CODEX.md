# Primer encargo para Codex

Actúa como desarrollador frontend senior con criterio comercial y especialista en landing pages B2B en Chile. Trabaja sobre este repositorio.

1. Lee `AGENTS.md`, `docs/BRIEF_DISENO.md`, `docs/PUBLICACION_CLOUDFLARE.md` y examina todo `sitio/` antes de editar.
2. Realiza una auditoría de la landing en desktop y mobile (1440, 768, 390 y 320px). Prioriza legibilidad, confianza, accesibilidad, rendimiento, SEO y captación de consultas; no una reescritura cosmética.
3. Revisa primero las rutas críticas: CTA principal, navegación, menú móvil, formulario, validaciones, checkbox y apertura de WhatsApp, página de privacidad, enlace de Ventora.
4. Identifica problemas P0/P1/P2 y corrige P0/P1 con cambios pequeños. No cambies stack ni añadas servicios de pago, cuentas o dependencias sin necesidad documentada.
5. Sustituye afirmaciones genéricas o que presupongan una agencia por voz directa, profesional y honesta. No inventes métricas, clientes, precios, testimonios o experiencia.
6. Mantén el caso Ventora separado; si falta evidencia visual real, deja una tarea documentada para incorporar screenshot autorizado, no generes uno falso.
7. Corre `python scripts/check_site.py`, haz pruebas de navegación móvil y desktop en navegador y entrega evidencia reproducible del resultado, sin afirmar pruebas que no ejecutaste.
8. Propón un checklist de publicación en Cloudflare Pages sin publicar ni comprar ningún recurso hasta autorización explícita.

Entrega: breve diagnóstico priorizado, archivos cambiados, pruebas reales ejecutadas, limitaciones y checklist para despliegue. Evita sobreingeniería.
